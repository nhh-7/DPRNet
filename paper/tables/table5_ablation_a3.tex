\textit{Notes.} Each variant is trained for $250$k iterations on DIV2K with seeds

usage), supporting C4's balancing mechanism. With three seeds available, enabling the balance
loss additionally lowers the seed-to-seed standard deviation on both benchmarks
($0.05\!\rightarrow\!0.02$\,dB) and on the usage entropy itself
($0.008\!\rightarrow\!0.003$), so C4's variance-reduction sub-claim is now supported directly.}

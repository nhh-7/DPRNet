## 摘要

在资源受限的平台上，轻量级单图像超分辨率（SR）必须在重建质量与模型开销之间取得平衡。内容感知路由（content-aware routing）通过将语义相关的 token 分组来改善这一平衡，但 CATANet 的 Token 聚合块（Token Aggregation Block, TAB）使用了跨批次的指数移动平均（EMA）中心、硬分配标签，以及一个耦合在一起的原型更新/确认步骤。我们提出**动态原型路由**（Dynamic Prototype Routing, DPR），这是一种可即插即用替换 TAB 的模块，保持 CATANet 主干和张量接口不变。DPR 从当前 token 直接构造逐图像（per-image）原型，用一个可学习的查询库（query bank）对其进行细化，用一个有界的可学习温度对 token 进行匹配，并将分配置信度带入 token 排序、全局门控和软回退（soft fallback）之中；一个平衡损失（balancing loss）用以抑制原型槽位坍塌。在 DIV2K 上训练、并在五个标准基准上以 $\times2/\times3/\times4$ 进行评估，DPRNet 保持在轻量级范围内，达到与 CATANet 相当的精度，并在多数基准单元上取得小幅提升。例如在 $\times4$ 时，它在 Urban100 上取得 $26.89$ dB，Multi-Adds 为 $52.14$ G。在相同的输入约定下，它比轻量级 Transformer 基线 SwinIR-light 和 SRFormer-light 使用更少的 Multi-Adds。多种子消融确认：动态原型优于采用指数移动平均的历史中心变体，且平衡损失使原型使用在种子间既更均衡又更稳定，同时路由诊断在软分配置信度下保持可解释。

**关键词：** 图像超分辨率；轻量级超分辨率；内容感知路由；动态原型路由；自注意力；视觉 Transformer；深度学习

**特色应用（Featured Application）：** 面向诸如移动端与边缘设备等资源受限平台的高效单图像超分辨率的置信度感知内容路由。

## 1. 引言

单图像超分辨率（SR）旨在从低分辨率（LR）观测重建出高分辨率（HR）图像，这一问题支撑着从移动摄影到显示渲染的众多应用。在深度学习之前，SR 常被用图像先验来建模，例如稀疏表示与图像内部自相似性 [yang2010sparse, glasner2009single]。自开创性深度模型 SRCNN [dong2014srcnn] 以来，精度通过更深的、递归的、渐进式的以及特征复用的网络不断提升，包括 VDSR [kim2016vdsr]、DRCN [kim2016drcn]、LapSRN [lai2017lapsrn]、DBPN [haris2018dbpn]、RDN [zhang2018rdn]、RCAN [zhang2018rcan] 和 EDSR [lim2017edsr]。近期一篇综述从架构、损失、数据集与指标等方面总结了这一发展脉络 [wang2021survey]。然而，参数量与计算量的相应增长使许多高容量模型在移动与边缘设备上难以实用，因为这些设备的内存、延迟和能耗都受到严格约束。这种张力催生了持续的**轻量级** SR 研究路线，其目标是在重建质量与模型开销之间寻求有利的折衷。

**基于 CNN 的轻量级 SR。**
高效的 CNN 设计通过将计算移到低分辨率特征上、复用参数、简化特征蒸馏，或用紧凑的混合运算替代重型算子来降低开销。FSRCNN 加速了 SRCNN 式的重建 [dong2016fsrcnn]，ESPCN 执行高效的亚像素上采样 [shi2016espcn]，递归式或基于记忆的设计在深度上复用特征 [tai2017drrn, tai2017memnet]。CARN 采用了带分组卷积的级联残差连接 [ahn2018carn]；IMDN 引入了信息多重蒸馏 [hui2019imdn]；RFDN 用残差特征蒸馏块重新表述了这一思想 [liu2020rfdn]；RLFN 进一步简化了局部特征提取以实现高效 SR [kong2022rlfn]。更近期的轻量级设计还探索了基于 shuffle 的卷积混合与双回归约束 [sun2022shufflemixer, guo2022dualregression]。高效 SR 挑战赛也体现了同样的部署压力，其对模型的排名综合考虑了精度、运行时、参数量和 FLOPs [ren2024ntire]。对于本工作而言，这些方法的主要局限不在效率，而在上下文：局部连接的卷积算子在不堆叠许多层的情况下，无法直接比较空间上相距较远但语义相似的区域。

**基于 Transformer 的轻量级 SR。**
长程建模从另一个方向应对上下文局限。非局部算子跨越较远位置聚合特征 [wang2018nonlocal]，基于 Transformer 的复原将这一思想用学习到的注意力加以扩展。IPT 表明大型预训练 Transformer 可服务于包括 SR 在内的图像复原任务 [chen2021ipt]，而 Swin Transformer 提供了平移窗口（shifted-window）算子，后续复原模型采用它来实现可处理的注意力 [liu2021swin]。SwinIR 为图像复原引入了基于窗口的注意力 [liang2021swinir]；ELAN 精简了长程注意力以削减冗余计算 [zhang2022elan]；SRFormer 用置换自注意力（permuted self-attention）重新审视了窗口—通道的折衷 [zhou2023srformer]；HAT 激活更多像素以扩大有效感受野 [chen2023hat]。高效变体进一步将局部算子与全维、n-gram 或层次化的注意力模式相混合 [zheng2023emt, wang2023omnisr, choi2023ngswin, liu2022hpinet]。ATD 用一个自适应 token 字典扩充局部窗口以扩展有效上下文 [zhang2024atd]。这些方法虽然有效，但窗口注意力仍将 token 交互绑定于固定的空间划分。因此语义相似但空间相距较远的 token，只有在窗口增大或引入额外全局路径时才会发生交互。

**内容感知 / 基于聚类的路由。**
一个互补的方向按**内容**而非空间位置对 token 分组，使得长程但语义相关的区域能够在一个紧凑的注意力内交互。这一思想与更早的自范例（self-exemplar）和非局部 SR 设计相关，在那些设计中，相似的图块或纹理对应关系被跨图像或跨参考显式挖掘 [glasner2009single, mei2020csnln, yang2020ttn]。SPIN 为轻量级 SR 执行基于超像素的 token 交互 [zhang2024spin]。CATANet 用一个 Token 聚合块（TAB）将该思想进一步推进：它维护一小组路由中心，将每个 token 分配到最近的中心，按聚类标签对 token 重排序，并用一个组内/组间注意力算子聚合重排后的序列 [liu2025catanet]。这种内容路由在低预算下带来了强劲的精度，是我们工作最直接的前身。

**基于中心的路由的局限。**
尽管有效，TAB 路由机制存在四点局限。(i) 其路由中心是通过一个带指数移动平均（EMA）缓冲的 $k$-means 式迭代跨批次维护的，因此这些中心由跨批次的历史状态驱动，而非严格由当前图像驱动，对逐图像语义的适应很缓慢。(ii) token 到中心的关系是一个硬 `argmax` 标签，丢弃了分配的**置信度**，把明确属于某个聚类的 token 与处在边界上的模糊 token 同等对待。(iii) 重排序只按标签对 token 聚类，没有聚类内纯度约束，因此聚合时高置信度与低置信度 token 在同一组内交错混杂。(iv) 原型**生成**与**确认**纠缠在单一的迭代更新中，削弱了可解释性与稳定性。这些观察表明：一个直接由当前输入构造、能保留并利用分配置信度、并将原型生成与确认相分离的路由模块，或可在不牺牲轻量级范围的前提下改进内容路由。

**我们的方法。**
我们提出**动态原型路由**（DPR），作为 TAB 路由的即插即用替换，保持 CATANet 主干及其外部张量接口不变，同时维持在可比的轻量级运行范围内。DPR 通过软分配直接从当前 token 生成语义原型，用一个与生成解耦的可学习查询库对其进行确认，用一个可学习温度将 token 匹配回已确认的原型，并将一个显式的逐 token 置信度贯穿排序与聚合过程。由此得到的网络 **DPRNet** 在 DIV2K 上训练，并在五个标准基准上以 $\times2/\times3/\times4$ 评估，在多数基准单元上取得小幅提升、并保持可比的轻量级开销画像的同时，维持了 CATANet 级别的重建质量，还暴露出一个可解释的、置信度感知的路由机制。

**贡献。**
主要贡献如下。

- **C1 —— 动态语义原型。** 我们通过软的、分配加权的聚合，从当前 token 生成路由原型，去除了跨批次的 EMA 中心缓冲，使原型跟随逐图像语义（第 [2.3](#23-动态原型路由) 节，公式 [(4)](#eq-assign)–[(5)](#eq-proto-content)）。
- **C2 —— 解耦的原型确认。** 我们通过一个门控交叉注意力，用一个可学习查询库对内容原型进行细化，从而将原型**生成**与**确认**分离，提升路由槽位的稳定性与可解释性（公式 [(6)](#eq-proto-refine)）。
- **C3 —— 置信度感知路由。** 我们显式保留 token 分配置信度，并用于三处：一个把高置信度 token 在每个聚类内排到前面的复合排序键，一个由置信度调制的全局门控，以及一个针对不确定 token 的软原型回退（公式 [(9)](#eq-sortkey)、[(10)](#eq-iasa-gate)、[(11)](#eq-soft-fallback)）。
- **C4 —— 稳定化路由。** 我们引入一个可学习的路由温度，配合一个原型使用平衡正则项，以缓解坍塌到少数原型上的问题并保持槽位使用分散（公式 [(7)](#eq-scores)、[(12)](#eq-balance)）。

每个设计要素都被暴露为一个独立开关，默认取全模型，关闭时退化为其禁用形式，因此这些贡献可以在消融研究中被干净地隔离（第 [3.5](#35-消融研究) 节）。

## 2. 方法

### 2.1 概览

我们在 CATANet 的轻量级超分辨率（SR）主干之上构建，并用一个**动态原型路由**（DPR）模块替换其 token 路由组件（图 [1](#图-1)）。给定一个低分辨率（LR）输入 $I_{LR}\in\mathbb{R}^{3\times H\times W}$，一个 $3\times3$ 卷积提取浅层特征 $F_0\in\mathbb{R}^{C\times H\times W}$（$C{=}40$）。深层特征提取器是 $L{=}8$ 个块的堆叠；每个块将一个内容路由的全局聚合单元（Token 聚合块，TAB）与一个局部自注意力单元（LRSA）耦合，随后接一个 $3\times3$ 融合卷积与一个残差连接：

$$F_l = F_{l-1} + \mathrm{Conv}_{3\times3}\!\big(\mathrm{LRSA}_l(\mathrm{TAB}_l(F_{l-1}))\big),\quad l=1,\dots,L. \tag{1}$$

一个全局残差把深层特征连接到网络输出，输出由一个 pixel-shuffle 上采样器重建并加到一张双线性上采样的基图上：

$$I_{SR} = \mathrm{Up}\big(F_0 + F_L\big) + \mathrm{Bilinear}_{\uparrow s}(I_{LR}), \tag{2}$$

其中 $s\in\{2,3,4\}$ 为缩放因子。本工作的贡献完全位于 TAB 内部：我们保持其外部接口 $\mathbb{R}^{C\times H\times W}\!\to\!\mathbb{R}^{C\times H\times W}$ 不变，用 DPR 流水线替换原来基于均值的中心迭代与硬标签排序（第 [2.3](#23-动态原型路由) 节），同时复用后续的组内/组间聚合算子（IASA，第 [2.4](#24-置信度感知聚合iasa) 节）。这使主干其余部分保持不变，从而隔离出路由机制的作用。

在一个 TAB 内部，输入特征图被展平为 token 序列 $X\in\mathbb{R}^{B\times N\times C}$（$N{=}HW$），经层归一化、由 DPR 路由、由 IASA 聚合，并由一个 $1\times1$ 卷积和一个卷积前馈网络（ConvFFN）融合，每一步都带残差连接。数据流为：

$$X \;\to\; \mathrm{DPR} \;\to\; \mathrm{IASA} \;\to\; \mathrm{Conv}_{1\times1} \;\to\; \mathrm{ConvFFN}. \tag{3}$$

### 2.2 动机：基于中心的路由的局限

原始 TAB 通过一个带指数移动平均（EMA）缓冲的 $k$-means 式迭代来维护一组路由中心，以 `argmax` 硬标签把每个 token 分配到其最近的中心，按该标签对 token 排序，并聚合排序后的序列，从而实现内容感知的重排序。该设计从四个方面促成了 DPR。(i) 这些中心由跨批次历史缓冲驱动，而非严格由当前输入驱动，因此对逐图像语义适应缓慢。(ii) token 到中心的关系是硬标签，丢弃了分配置信度。(iii) 排序仅按标签聚类，没有聚类内纯度约束。(iv) 原型生成与原型确认相纠缠，削弱了可解释性。DPR 的回应是：从当前 token 生成原型，将生成与确认解耦，并将一个显式的分配置信度贯穿路由与聚合。

### 2.3 动态原型路由

DPR 把一个 token 序列 $X\in\mathbb{R}^{B\times N\times C}$ 映射为一个内容重排序的序列、$M$ 个动态原型，以及路由元数据。流水线包含四个阶段（图 [2](#图-2)）。

**(1) 动态原型生成。**
我们首先用一个轻量级头对 token 进行嵌入 $E = \mathrm{GELU}(\mathrm{Linear}(\mathrm{LN}(X)))\in\mathbb{R}^{B\times N\times C}$，并预测每个 token 到 $M$ 个原型槽位的软分配：

<a id="eq-assign"></a>
$$A = \mathrm{softmax}\big(E W_a\big)\in\mathbb{R}^{B\times N\times M},\quad W_a\in\mathbb{R}^{C\times M}, \tag{4}$$

其中 softmax 取在 $M$ 个槽位上。每个原型是**当前** token 的分配加权平均：

<a id="eq-proto-content"></a>
$$P^{\mathrm{c}}_{m} = \frac{\sum_{n} A_{n,m}\, X_{n}}{\sum_{n} A_{n,m} + \epsilon},\qquad P^{\mathrm{c}} = \mathrm{normalize}\big(\mathrm{LN}(P^{\mathrm{c}})\big), \tag{5}$$

沿通道维度做 $\ell_2$ 归一化。与基线的 EMA 中心不同，$P^{\mathrm{c}}$ 仅依赖当前输入，不携带任何跨批次状态。

**(2) 通过查询细化的原型确认。**
为把原型**生成**与**确认**分离，我们用一个可学习查询库 $Q\in\mathbb{R}^{M\times C}$ 通过一次对 token 的交叉注意力来细化 $P^{\mathrm{c}}$。以查询种子 $\tilde{P}=P^{\mathrm{c}}+Q$、由种子给出的查询、由嵌入/原始 token 给出的键/值：

$$P^{\mathrm{r}} = \mathrm{softmax}\!\Big(\tfrac{(\tilde{P}W_q)(E W_k)^{\!\top}}{\sqrt{d_r}}\Big)\,(X W_v),$$

其中 $d_r$ 为路由器维度。该细化通过一个可学习门控 $\gamma=\sigma(g_r)\in(0,1)$ 融合：

<a id="eq-proto-refine"></a>
$$P = \mathrm{normalize}\big(\mathrm{LN}(P^{\mathrm{c}} + \gamma\,P^{\mathrm{r}})\big). \tag{6}$$

将 $g_r$ 初始化为一个较小的值，可使细化在训练开始时保持为一个残差扰动，这有助于让原型身份在不同样本间保持稳定。该阶段可被禁用（消融 A1），只需令 `use_prototype_query_refine=false`，此时退化为 $P=P^{\mathrm{c}}$。

**(3) 置信度感知的 token 到原型匹配。**
我们在一个共享的 $\ell_2$ 归一化路由空间中将 token **匹配回**已确认的原型，$\hat{e}_n=\mathrm{normalize}(E_n W_t)$、$\hat{p}_m=\mathrm{normalize}(P_m W_p)$，并用一个**可学习温度** $\tau$ 计算路由分数：

<a id="eq-scores"></a>
$$S = \mathrm{softmax}\big(\tau\,\hat{E}\hat{P}^{\!\top}\big)\in\mathbb{R}^{B\times N\times M},\qquad \tau = \min\!\big(e^{\,\theta},\,\tau_{\max}\big), \tag{7}$$

其中 $\theta$ 是一个可学习的对数尺度，由 $\tau_{\max}$ 钳制以保证稳定性。更大的 $\tau$ 会锐化分配分布并增大路由分数的区分度。对每个 token，我们读出其硬标签及其置信度：

<a id="eq-belong"></a>
$$x^{\mathrm{s}}_n = \max_m S_{n,m},\qquad b_n = \arg\max_m S_{n,m}, \tag{8}$$

并**显式保留**置信度 $x^{\mathrm{s}}_n$（以此弥补 TAB 所丢弃的硬标签置信度）。

**(4) 置信度感知排序。**
我们不再仅按聚类标签排序，而是使用一个复合键，既保持聚类间的次序，又在每个聚类**内部**把高置信度 token 排到前面：

<a id="eq-sortkey"></a>
$$k_n = b_n + 0.5\,\big(1 - x^{\mathrm{s}}_n\big),\qquad \pi = \mathrm{argsort}_n(k_n). \tag{9}$$

由于 $x^{\mathrm{s}}_n\in(0,1)$，附加项落在 $(0,0.5)$ 内，绝不会跨越整数标签边界，因此各聚类保持连续，而其成员按置信度排序。token 序列、标签和置信度由 $\pi$ 收集为 $X^{\pi},\,b^{\pi},\,x^{\mathrm{s},\pi}$，并记录逆排列 $\pi^{-1}$ 以便散射回原位。令 `use_conf_sort=false` 时，公式 [(9)](#eq-sortkey) 退化为纯标签排序 $k_n=b_n$（消融 A2）。

DPR 输出重排序后的 token $X^{\pi}$、动态原型 $P$、完整分数图 $S$，以及逐 token 置信度 $x^{\mathrm{s}}$，供下面的聚合器使用。

### 2.4 置信度感知聚合（IASA）

聚合算子保留自主干，但被改造为置信度感知。在重排序序列 $X^{\pi}$ 上，它计算：(a) 在大小为 $g$ 的重叠组上的组内局部注意力，用以在每个连续、语义连贯的片段内捕获精细的局部结构；以及 (b) 一个全局分支，它对投影为键/值的动态原型 $P$ 进行注意力。令 $O_{\mathrm{loc}}$ 与 $O_{\mathrm{glb}}$ 表示两个分支的输出。它们通过一个由逐 token 置信度调制的可学习全局门控 $\beta=\sigma(g_g)$ 组合：

<a id="eq-iasa-gate"></a>
$$O = O_{\mathrm{loc}} + \beta\cdot x^{\mathrm{s},\pi}\cdot O_{\mathrm{glb}}, \tag{10}$$

因此低置信度 token 更少地依赖全局原型摘要。输出经 $\pi^{-1}$ 散射回原始 token 次序并投影。令 `use_iasa_score_gate=false` 会移除公式 [(10)](#eq-iasa-gate) 中的置信度因子（$O = O_{\mathrm{loc}} + \beta\,O_{\mathrm{glb}}$；消融 A2）。

**软原型回退。**
为稳定那些硬分配不确定的 token，DPR 向聚合输出加入一个软的、置信度加权的原型上下文。以软摘要 $\bar{X}=S P$ 经 $W_s$ 投影、以及一个可学习门控 $\alpha=\sigma(g_s)$：

<a id="eq-soft-fallback"></a>
$$Y = O + \alpha\,\big(1 - x^{\mathrm{s}}\big)\,\big(\bar{X}W_s\big), \tag{11}$$

其中 $(1-x^{\mathrm{s}})$ 强调低置信度 token。结果 $Y$ 经过 $1\times1$ 卷积、残差连接和 ConvFFN。令 `use_soft_fallback=false` 会把公式 [(11)](#eq-soft-fallback) 退化为 $Y=O$（消融 A2）。公式 [(9)](#eq-sortkey)、[(10)](#eq-iasa-gate) 与 [(11)](#eq-soft-fallback) 共同构成置信度感知路由通路，三个开关相互独立，默认取全模型。

### 2.5 原型使用平衡

一个可学习温度可能把路由集中到少数原型上。因此我们加入一个使用熵（usage-entropy）正则项，以鼓励平衡的槽位使用。令 $u_m=\frac{1}{N}\sum_n S_{n,m}$ 为原型 $m$ 的平均使用；其归一化熵与辅助损失为：

<a id="eq-balance"></a>
$$\mathcal{H}(u) = -\frac{1}{\log M}\sum_{m} u_m\log u_m,\qquad \mathcal{L}_{\mathrm{bal}} = \lambda\,\big(1 - \mathcal{H}(u)\big), \tag{12}$$

当使用均匀时该式取最大（损失最小）。总目标把这一项（对所有块求和）加到像素重建损失上：

$$\mathcal{L} = \mathcal{L}_{\mathrm{pix}} + \sum_{l}\mathcal{L}^{(l)}_{\mathrm{bal}}. \tag{13}$$

令逐块权重 $\lambda{=}0$ 即禁用平衡（消融 A3）。

### 2.6 设计讨论

DPR 保持主干接口与参数预算处于轻量级范围，只改变在聚合之前 token 的组织方式。四个阶段直接对应各项贡献：动态生成（公式 [(4)](#eq-assign)–[(5)](#eq-proto-content)）对应 C1，生成/确认解耦（公式 [(6)](#eq-proto-refine)）对应 C2，置信度感知路由（公式 [(7)](#eq-scores)–[(9)](#eq-sortkey)、[(10)](#eq-iasa-gate)–[(11)](#eq-soft-fallback)）对应 C3，可学习温度加使用平衡（公式 [(7)](#eq-scores)、[(12)](#eq-balance)）对应 C4。因为每个设计要素都被暴露为一个默认取全模型、关闭时退化为其禁用形式的独立开关，这些贡献可以在消融研究中被干净地隔离（第 [3.5](#35-消融研究) 节）。

## 3. 实验

### 3.1 数据集与实现细节

**数据集与指标。**
遵循标准的轻量级 SR 协议，我们在 DIV2K [agustsson2017div2k] 的 $800$ 张训练图像上训练，并在五个基准上评估：Set5 [bevilacqua2012set5]、Set14 [zeyde2010set14]、BSD100 [martin2001bsd100]、Urban100 [huang2015urban100] 与 Manga109 [matsui2017manga109]。低分辨率输入由 $\times2$、$\times3$ 和 $\times4$ 的双三次（bicubic）下采样产生。我们在 YCbCr 空间的 Y 通道上报告 PSNR 与 SSIM [wang2004ssim]，对缩放 $s$ 舍弃 $s$ 像素的边界，这与所引基线所用的约定一致。

**网络配置。**
DPRNet 保持 CATANet 主干不变，仅将每个 TAB 内部的路由替换为 DPR 模块（第 [2](#2-方法) 节）。深层特征提取器堆叠 $L{=}8$ 个块，通道宽度 $C{=}40$。每块的原型槽位数为 $M=[16,32,64,128,16,32,64,128]$，组内注意力使用 $128$ 的组大小。可学习路由温度初始化为 $\tau{=}6$（即对数尺度参数 $\theta{=}\log 6$），并钳制在 $\tau_{\max}{=}10$（公式 [(7)](#eq-scores)）；逐块使用平衡权重前六块为 $\lambda=[5{\times}10^{-4}]_{\times6}$，最后两块为 $7{\times}10^{-4}$（公式 [(12)](#eq-balance)）。这些配置在不同缩放下产生 $0.60$–$0.67$ M 参数（表 [2](#表-2)）。

**训练。**
我们对 $\times2$ 模型训练 $800$k 次迭代，对 $\times3$ 和 $\times4$ 模型分别训练 $250$k 次迭代。训练图块对 $\times2/\times3/\times4$ 分别为 $128{\times}128$、$192{\times}192$ 和 $256{\times}256$ 的 HR 裁剪，批大小为 $16$，并以随机水平翻转和 $90^{\circ}$ 旋转作数据增广。我们用 Adam（$\beta_1{=}0.9$，$\beta_2{=}0.99$，无权重衰减）在初始学习率 $2{\times}10^{-4}$ 下优化 L1 重建损失连同使用平衡正则项（公式 [(12)](#eq-balance)），学习率按 MultiStep 计划减半（$\times2$ 的里程碑为 $\{300,500,650,700,750\}$k，$\times3/\times4$ 为 $\{125,200,225,237.5\}$k）。可学习路由温度以 $0.1{\times}$ 的学习率乘子训练以保证稳定。每 $2.5$k 次迭代运行一次验证。实验使用 PyTorch 与 BasicSR 框架，在单块 NVIDIA RTX 4090 GPU 上进行。

**效率测量。**
参数量、Multi-Adds（由 thop 报告的 MACs）与推理延迟，在单块 NVIDIA RTX 4090 GPU 上、以固定 LR 输入 $256{\times}256$（$\times4$ 输出 $1024{\times}1024$）测量，经 $20$ 次预热后在 $100$ 次运行上取平均。此输入约定与 CATANet 论文为其自身及轻量级 Transformer 基线报告 Multi-Adds 时所用的约定一致，使各数字可直接比较。高效 SR 挑战赛的报告同样把运行时、参数量和 FLOPs 视为联合部署准则而非附属统计 [ren2024ntire]。为与基于 FLOPs 的报告比较，将 Multi-Adds 值乘以二。

### 3.2 与最新方法的比较

我们将 DPRNet 与八个具代表性的轻量级 SR 方法比较。CNN 组包含 CARN [ahn2018carn]、IMDN [hui2019imdn]、RFDN [liu2020rfdn] 和 RLFN [kong2022rlfn]，而 Transformer 与路由组包含 SwinIR-light [liang2021swinir]、ELAN-light [zhang2022elan]、SRFormer-light [zhou2023srformer]，以及直接前身 CATANet [liu2025catanet]。竞争方法的数字引自其原始论文，如表 [1](#表-1) 所注。DPRNet 在每个缩放下的全部五个基准上报告。

**总体精度。**
表 [1](#表-1) 显示，DPRNet 与 CATANet 在全部三个缩放上构成第一梯队，在 Urban100 和 Manga109 上分离最为明显，而在 Set5、Set14 与 BSD100 上差距较小。例如在 $\times4$ 时，DPRNet 在 Set5 上达到 $32.59$ dB/$0.9002$、在 BSD100 上达到 $27.76$ dB/$0.7434$，相比之下 SRFormer-light 在可比参数预算下为 $32.51$/$0.8988$ 和 $27.73$/$0.7422$。这一模式表明，当重复或语义相关的结构出现在相距较远的位置时，内容感知的 token 聚合在轻量级范围内尤其有用。

**与 CATANet 的比较。**
相对于 CATANet——最强基线，也是 DPRNet 仅在路由模块上有所不同的对象——DPRNet 在几乎每个基准/缩放单元上排名第一或并列第一，CATANet 通常居第二。差距虽小但方向一致：在 $\times4$ 时，DPRNet 将 Urban100 从 $26.87$/$0.8081$ 提升到 $26.89$/$0.8089$、Set5 从 $32.58$/$0.8998$ 提升到 $32.59$/$0.9002$、Set14 从 $28.90$/$0.7880$ 提升到 $28.91$/$0.7883$、Manga109 PSNR 从 $31.31$ 提升到 $31.32$；在 $\times2$ 时，它取得最优的 Set14（$34.06$/$0.9220$）、Urban100 PSNR（$33.15$）与 Manga109（$39.38$/$0.9789$）；在 $\times3$ 时，它在每个基准上领先或持平 CATANet（例如 BSD100 $29.29$/$0.8103$、Urban100 $29.06$/$0.8689$）。CATANet 仍领先的唯一指标是 $\times4$ 时的 Manga109 SSIM（$0.9183$ 对 $0.9181$）。这些差距都在几百分之一 dB 以内。因此结果支持一个保守结论：将 TAB 的 EMA 中心路由替换为 DPR 的动态原型路由，在把路由机制改为第 [3.5](#35-消融研究) 节和第 [3.6](#36-路由可解释性分析) 节所分析的可解释、置信度感知形式的同时，保持了 CATANet 级别的重建质量。

**效率。**
表 [2](#表-2) 报告 $\times4$ 效率子集，涵盖那些在相同固定 $256{\times}256$ LR 输入约定下有 Multi-Adds 可用的方法。DPRNet 有 $660$K 参数与 $52.14$ G Multi-Adds，使其保持在轻量级区间内。它比轻量级 Transformer 基线 SwinIR-light（$60.3$ G）和 SRFormer-light（$56.5$ G）使用更少的 Multi-Adds，同时给出有竞争力的第一梯队精度。它的参数量与 Multi-Adds 都比 CATANet 略高（$\times4$ 时 $660$K/$52.14$ G 对 $535$K/$46.8$ G），这反映了 DPR 的可学习查询库与路由器投影，因此我们不宣称相对 CATANet 有效率优势。DPRNet 的逐缩放画像（含在我们硬件上测得的延迟）见表 [3](#表-3)。在不兼容约定下报告的跨论文延迟与计算值，被排除在表 [2](#表-2) 之外，而非混入同一数值比较。

### 3.3 模型复杂度与效率

表 [2](#表-2) 在 $\times4$ 下比较那些在相同输入约定下有 Multi-Adds 可用的方法子集的模型复杂度，表 [3](#表-3) 给出 DPRNet 的逐缩放画像。所有 DPRNet 数字均按第 [3.1](#31-数据集与实现细节) 节的协议、以固定 $256{\times}256$ LR 输入（$\times4$ 输出 $1024{\times}1024$）测量，报告 thop MACs 与经 $20$ 次预热后 $100$ 次运行的延迟。我们采用这一 $256{\times}256$ 输入约定，是因为它正是 CATANet 论文为其自身、SwinIR-light 和 SRFormer-light 报告 Multi-Adds 时所用的约定；因此 DPRNet 的 MACs 可与那三个所引数字直接比较。若某方法所发布的计算值采用了不同约定，或在此约定下不可获得，则将其排除出效率子集，而非以空白项显示。

**参数量。**
DPRNet 以 $660$K 参数（$\times4$）保持在轻量级区间内，与 ELAN-light（$601$K）等 Transformer 基线相当，并远低于 SwinIR-light（$897$K）、SRFormer-light（$873$K）以及偏重的 CNN CARN（$1592$K）。不过，它比其直接前身 CATANet（$535$K）更大：DPR 的可学习查询库与路由器/分数投影相对 CATANet 的 EMA 中心路由增加了参数。因此与 CATANet 的比较是在**同等或更优精度**的框架下进行的，而非作为参数优势（Urban100 $26.89$ 对 $26.87$，完整消融分析见第 [3.5](#35-消融研究) 节）。图 [3](#图-3) 绘出了 $\times4$ 下 Urban100 上的这一 PSNR–参数折衷：DPRNet 在所比较的轻量级方法中取得最高 PSNR，同时保持在同一参数区间内。

**计算量。**
就 Multi-Adds 而言，DPRNet 在统一 $256{\times}256$ 协议下于 $\times4$ 需要 $52.14$ G。这高于 CATANet 的 $46.8$ G，因此 DPR 的可学习查询库与路由器/分数投影相对 CATANet 的 EMA 中心路由确实增加了推理开销。因此我们不对 CATANet 作任何计算量声明，比较保持在**同等或更优精度**（Urban100 $26.89$ 对 $26.87$，完整消融见第 [3.5](#35-消融研究) 节）。相对 Transformer 基线，其计算画像更为有利：在相同输入尺寸下，DPRNet 使用的 Multi-Adds 明显少于 SwinIR-light（$60.3$ G）和 SRFormer-light（$56.5$ G），同时在表 [2](#表-2) 中取得最优 Urban100 PSNR。因此 DPRNet 稳固地处于轻量级区间内，以相对其直接前身的适度开销增加换取了一个可解释的、置信度感知的路由机制，并在更高精度下相对注意力密集的 Transformer 设计取得明显的开销降低。

**逐缩放行为。**
表 [3](#表-3) 报告固定 $256{\times}256$ LR 输入下的画像。由于输入尺寸保持恒定，主干开销在各缩放间共享，Multi-Adds 由上采样尾部主导，因此随缩放因子**增长**——从 $36.19$ G（$\times2$）到 $41.26$ G（$\times3$）与 $52.14$ G（$\times4$）。延迟遵循相同次序（$183.57$、$185.88$、$198.16$ ms）。参数量基本与缩放无关（$\approx0.60$–$0.67$ M），因为只有输入投影和上采样尾部随缩放变化。

**效率比较的范围。**
主精度表（表 [1](#表-1)）仍是对全部八个基线的完整比较。效率表则有意更窄：它只报告共同协议下的 MACs 以及 DPRNet 测得的逐缩放运行时。我们不跨不同设备或实现栈混用延迟值，也不导入在不兼容的输入尺寸或 FLOPs 计数约定下报告的计算数字。这使表 [2](#表-2) 成为一个可直接比较的效率子集，而非一张含不可比条目的全方法表。

### 3.4 定性比较

除聚合的 PSNR/SSIM 外，图 [4](#图-4) 比较了在 $\times4$ 下、按真值高频能量选出的三个纹理密集的困难样本的重建：两张由重复建筑网格主导的 Urban100 图像（`img_092`、`img_024`）和一页高对比度线条艺术的 Manga109（`ThatsIzumiko`）。这些正是内容路由预期最有帮助的情形，因为共享同一结构的远距 token 可以被聚合到一起，而不仅在局部窗口内聚合。

在 Urban100 的重复立面上，双三次基线把相邻窗口边缘坍缩成模糊、混叠的条带，轻量级 CNN IMDN 也仅部分恢复它们。基于 Transformer 的方法（SwinIR-light、SRFormer-light、CATANet）逐步锐化了网格结构，而 DPRNet 以干净、良好分隔的边界重建了窗口间距，与最强的内容路由基线 CATANet 相当。在 Manga109 线条艺术上，细笔画容易被上采样打断，DPRNet 保持轮廓连续并避免明显的振铃，达到最佳 Transformer 基线的视觉质量。这些观察与第 [3.6](#36-路由可解释性分析) 节的路由诊断一致：置信度感知聚合追踪结构化的高频区域，而局部窗口方法对这些区域的还原不够忠实。我们强调，图 [4](#图-4) 是一个定性比较；所有基线对应的定量结果见表 [1](#表-1)，其中 DPRNet 在可比参数预算下仍处于第一梯队。

### 3.5 消融研究

我们用第 [2](#2-方法) 节所暴露的独立开关对 DPR 的四个设计要素进行消融。所有消融均在 $\times4$ 缩放下进行，遵循 CATANet [liu2025catanet]（其消融同样在 $\times4$ 进行），这是对高频纹理上内容路由压力最大的设置。每个变体在 DIV2K 上、按与全模型相同的调度从头训练 $250$k 迭代，并在三个种子 $\{3407,42,1234\}$ 上重复。我们在验证最优检查点（按 Set5$+$Urban100 均值、Y 通道、匹配的 `crop_border` 选取）报告三个种子的 mean$\pm$std。除 PSNR/SSIM 外，我们逐 TAB 块记录路由诊断——公式 [(12)](#eq-balance) 的归一化原型使用熵 $\mathcal{H}(u)$、活跃原型使用量，以及可学习温度——以直接检查路由行为。由于每个变体都在同一协议下独立训练，下面的差异反映的是被切换要素本身的贡献；报告三个种子进一步让我们不仅能比较平均效应，也能比较其在不同运行间的稳定性。

**C1：动态原型 vs. 历史中心。**
表 [4](#表-4) 直接比较 DPR 的动态、逐图像原型生成（全模型）与一个带 EMA 更新的跨批次历史中心（**EMA-center**）——后者是对基线中心机制的重新实现，保持完全相同的主干、接口以及原型生成器下游的一切。在此匹配协议下，动态原型在两个基准上都给出更好的重建（Set5 $32.57$ 对 $32.51$ dB，Urban100 $26.87$ 对 $26.76$ dB），且种子间方差更低。这为 C1 提供了直接的受控确认：从当前 token 构造原型、而非跨批次累积原型，才是改进路由的原因——而非仅仅是容量或训练预算的差异（二者在此被固定）。

**A1：解耦的原型确认。**
表 [5](#表-5) 比较有无查询细化阶段的 DPR（公式 [(6)](#eq-proto-refine)）。启用 refine 在两个基准上都改善结果（Set5 $32.57$ 对 $32.53$ dB；Urban100 $26.87$ 对 $26.82$ dB），且由于该增益（约 $0.04$–$0.05$ dB）超过种子间标准差（约 $0.02$–$0.04$ dB），它可归因于 refine 开关本身而非运行间噪声。该细化由一个小初始化标量门控（公式 [(6)](#eq-proto-refine)），因此起到一个残差确认步骤的作用，在解耦生成与确认（C2）的同时保持原型槽位稳定；因此我们默认保留它。

**A2：置信度感知路由。**
表 [6](#表-6) 累积地加入三个置信度感知组件：置信度感知排序（公式 [(9)](#eq-sortkey)）、IASA 分数门控（公式 [(10)](#eq-iasa-gate)）和软原型回退（公式 [(11)](#eq-soft-fallback)）。全配置（v4）在 Set5 和 Urban100 上都明显是四者中最佳，且超出种子标准差。然而中间步骤并非单调——单独加入排序与门控会在完整集合恢复并超过硬路由基线之前略微降低 PSNR。因此我们把这三个开关读作相互相容、且以**完整**置信度感知通路最为有效，而非每个开关在精度上单独可加。我们保留这些组件，因为它们使路由通路可解释且由置信度驱动：保留的逐 token 置信度 $x^{\mathrm{s}}$ 调制排序、全局门控和回退（C3），我们在第 [3.6](#36-路由可解释性分析) 节通过 $x^{\mathrm{s}}$ 分布将其可视化。

**A3：原型使用平衡。**
表 [7](#表-7) 隔离出使用平衡正则项（公式 [(12)](#eq-balance)）。启用它把 Urban100 上块平均归一化使用熵从 $0.623$ 提升到 $0.686$，且这一提升在全部八个 TAB 块（$b_0$–$b_7$；表 [8](#表-8)）上**一致**，即该正则项驱动了对原型槽位更平衡的使用，并抵消了可学习温度本会鼓励的坍塌（C4）。启用该正则项时重建质量也略高（Set5 $32.57$ 对 $32.55$ dB；Urban100 $26.87$ 对 $26.85$ dB），因此该平衡并未以精度换取更平坦的使用分布。关键在于，如今有了三个种子，我们可以评估 C4 的第二部分：启用平衡损失在两个基准上都**降低**了种子间标准差（$0.05\!\rightarrow\!0.02$ dB），在使用熵本身上也是如此（$0.008\!\rightarrow\!0.003$）。因此该正则项使精度与路由行为在种子间都更稳定，支持了 C4 的方差降低子主张，而不仅是平衡机制。

**小结。**
在三个种子上，消融表明 DPR 的设计要素质量保持到正向且相互相容——全模型在每一组中都是最佳变体。除平均效应外，本研究还实证了两个机制性主张：动态原型在匹配协议下优于 EMA 历史中心（C1），且使用平衡正则项既逐块一致地提升原型使用熵、又降低种子间方差（C4）。

### 3.6 路由可解释性分析

为独立于 PSNR 效应之外检查 DPR 的路由行为，我们分析在 $\times4$ 验证期间记录的诊断（Urban100，全模型）。对 $L{=}8$ 个 TAB 块中的每一个，我们记录逐 token 路由置信度 $x^{\mathrm{s}}=\max_m S_{n,m}$（公式 [(8)](#eq-belong)）、**活跃**原型的数量（至少接收一个 token 的槽位）、归一化使用熵 $\mathcal{H}(u)$（公式 [(12)](#eq-balance)），以及学到的温度 $\tau$（公式 [(7)](#eq-scores)）。各块分别使用 $M=[16,32,64,128,16,32,64,128]$ 个原型。

**平衡的原型使用（C4）。**
图 [6](#图-6) 报告有无平衡正则项时每块的归一化使用熵。启用平衡（全模型）时，熵在**全部八个**块中都更高，将块均值从 $0.623$ 提升到 $0.686$；效应在面向高频的块 $b_4$ 上最大（$0.709\!\rightarrow\!0.847$）。相应地，各块平均活跃原型数从 $47.5$ 增加到 $52.3$，意味着更少的槽位被闲置。由于可学习温度本会锐化分配分布并把 token 集中到少数原型上，这两项测量共同表明该正则项保持原型使用分散并防止槽位坍塌，与 C4 所声称的稳定化作用相符。

**有界的路由温度（C4）。**
可学习温度为稳定性由 $\tau_{\max}{=}10$ 钳制（公式 [(7)](#eq-scores)）。在训练好的全模型中，它在各块间稳定在一个适中范围（逐块 $\tau$ 从 $5.65$ 到 $6.51$，块均值 $6.06$），远低于钳制值而非饱和于它。因此该温度把路由分数锐化到足以分离原型的程度，同时使用正则项防止分配坍塌——两个 C4 组件如预期般起作用，且未触及其安全上界。

**置信度感知的路由信号（C3）。**
驱动排序键（公式 [(9)](#eq-sortkey)）、IASA 门控（公式 [(10)](#eq-iasa-gate)）和软回退（公式 [(11)](#eq-soft-fallback)）的逐 token 置信度 $x^{\mathrm{s}}$ 在每个块中都是一个非退化信号。图 [5](#图-5) 展示了用最终模型在 Urban100 和 Manga109 的**全部**测试图像上累积得到的分布：在每个块中，质量明显位于均匀分配下限 $1/M$ 的右侧（例如 Urban100 块均值在 $b_0$ 为 $0.109$ 对 $0.0625$，在 $b_3$ 为 $0.012$ 对 $0.0078$），但仍远离 $1$。因此 softmax 分配是有信息量的、但为柔性而非坍塌到单个原型，且随 $M$ 增大其众数向较低的下限移动。将原始次序标签 $b_n=\arg\max_m S_{n,m}$ 重塑为 $H\times W$，得到图 [7](#图-7) 的路由聚类图：其划分跟随图像内容（重复的建筑立面、高对比度笔画），而非固定的空间网格。在此可视化中，重要证据是边界连续性而非确切色调：早期块形成粗粒度内容组，而更深、更大 $M$ 的块把重复结构分裂为更细的划分。两种视图都由带缓存路由状态（`last_routing_map`、`last_x_scores`）的一次前向产生，共同确认 C3 组件所用的置信度是有意义的。

**小结。**
所记录的诊断为路由设计提供了机制层面的证据：平衡正则项在使用熵与活跃原型数上产生逐块一致的提升（C4），可学习温度停留在一个稳定、未饱和的范围（C4），且保留的置信度信号在所有块上都有信息量（C3）。这些观察独立于第 [3.5](#35-消融研究) 节讨论的重建指标，刻画了 DPR 的行为。

## 4. 讨论

**内容路由与空间局部性。**
第 [3.2](#32-与最新方法的比较) 节的基准结果指出内容感知路由在何处帮助最大。在 Urban100 和 Manga109 上——由重复结构和长程自相似性主导的图像——DPRNet 和 CATANet 这两个路由方法与基于窗口和蒸馏的基线分离得更为明显，而在 BSD100 更随机的纹理上，所有第一梯队方法之间的差距收窄。这与内容路由的前提以及更早利用内部自相似性或跨尺度非局部对应的 SR 工作相一致 [glasner2009single, huang2015urban100, mei2020csnln]：按语义对 token 分组，在语义相关内容空间分散时最为有用，而在局部统计已能捕获信号时用处较小。DPR 并不摒弃空间局部性；它是对其的补充，因为每个 TAB 都与一个局部自注意力单元配对（第 [2.1](#21-概览) 节）；路由模块提供了固定空间窗口无法提供的长程、基于内容的交互。

**小差距与证据强度。**
相对 CATANet 的数值差距被有意地框定为小。因此 DPR 的价值不在于宣称相对其直接前身有大的 PSNR 增益，而在于三条证据线的组合：在五个基准和三个缩放上一致的第一梯队位置（第 [3.2](#32-与最新方法的比较) 节）、相对注意力密集的 Transformer 基线保持的轻量级画像（第 [3.3](#33-模型复杂度与效率) 节），以及展示有意义置信度分数和更平衡原型使用的显式路由诊断（第 [3.6](#36-路由可解释性分析) 节）。这一框架很重要，因为现代轻量级 SR 方法在标准 PSNR/SSIM 评估下常仅相差几百分之一 dB；若无机制层面的分析，这类小差异本身是薄弱的证据。

**过强路由的风险。**
一个置信度感知路由器原则上可以锐化其分配直到 token 坍塌到少数原型上，这将挫败路由的目的并使训练不稳定。DPR 的两个组件被明确地设计来对抗这一失效模式：路由温度被钳制（公式 [(7)](#eq-scores)），使用平衡正则项（公式 [(12)](#eq-balance)）惩罚尖峰的使用分布。第 [3.6](#36-路由可解释性分析) 节的诊断表明两个机制都如预期般运作——学到的温度稳定在一个适中、未饱和的范围（块均值 $6.06$，低于 $10$ 的钳制值），且平衡正则项在全部八个块上提升了原型使用熵（$0.623\!\rightarrow\!0.686$），同时增加了活跃原型的数量。因此，置信度感知路由的收益是在不让路由器退化的情况下获得的。

**原型数量与开销折衷。**
DPR 使用逐块原型预算 $M=[16,32,64,128,16,32,64,128]$，在每个阶段内递增。更多原型给路由器更细的内容词汇，但会增大查询库和匹配开销，而太少的原型会迫使无关 token 共享一个槽位。我们让原型计划与 CATANet 主干对齐，以使比较隔离出路由机制而非容量变化；这也是为什么 DPRNet 比 CATANet 携带略高的参数量和 Multi-Adds（$\times4$ 下、共同 $256{\times}256$ 输入时 $660$K/$52.14$ G 对 $535$K/$46.8$ G），因为增加的开销存在于 DPR 的查询库和投影中。即便如此，DPRNet 仍处于轻量级区间内，并在更高精度下低于 Transformer 基线 SwinIR-light（$60.3$ G）和 SRFormer-light（$56.5$ G）（第 [3.3](#33-模型复杂度与效率) 节）。对原型计划的系统性扫描是一个自然的扩展，但与此处研究的路由表述正交。

**局限。**
若干局限限定了本研究并保守地框定我们的声明。消融（第 [3.5](#35-消融研究) 节）在三个种子上训练每个变体，这支持单开关归因，并让我们既报告平均效应又报告其种子间方差；尽管如此，相对最强配置的差距仍然很小，因此我们把这些设计要素框定为质量保持到正向且相互相容，而非大的单独增益。对重新实现的 EMA 中心分支的直接比较（C1）仅在 $\times4$ 的 Set5 与 Urban100 上进行——这是内容路由压力最大的设置——而非跨全部五个基准。效率比较有意限于共同协议下的 MACs 与我们测得的 DPRNet 运行时：我们不宣称跨方法延迟，因为竞争模型未在同一硬件与实现栈上重新测量（第 [3.3](#33-模型复杂度与效率) 节）。最后，模型仅在 DIV2K 上训练；更大的训练集（例如 DF2K）以及真实世界或任意缩放退化未在此探索，可能进一步改变折衷。

## 5. 结论

我们提出了动态原型路由（DPR），作为 CATANet 基于中心的 Token 聚合块的即插即用替换，在保持主干与张量接口不变的同时维持在可比的轻量级运行范围内。DPR 直接从当前 token 生成语义原型，通过一个可学习查询库解耦其确认，用一个可学习温度将 token 匹配回去，并将一个显式的逐 token 置信度贯穿排序、门控和软回退，配以一个保持原型使用分散的使用平衡正则项。在五个标准基准上以 $\times2/\times3/\times4$ 评估，由此得到的 DPRNet 在多数基准单元上取得小幅提升、并保持可比的轻量级开销画像的同时，维持了 CATANet 级别的重建质量。在三个种子上，消融归因了每个设计要素的效应，并表明动态原型优于一个重新实现的 EMA 历史中心，同时路由诊断提供了机制层面的证据：温度保持未饱和，原型使用在所有块上变得可测量地更平衡——且在种子间更稳定。由于 DPR 保持了路由块的外部接口，它不被绑定于此主干，可作为一个置信度感知的内容路由模块服务于其他 token 聚合架构。未来工作包括：在单一实现协议下重新测量所有比较模型以获得跨方法运行时，以及将 DPR 扩展到更大的训练集和真实世界或任意缩放退化。

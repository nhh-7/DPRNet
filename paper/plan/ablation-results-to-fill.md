## 0. 开跑前 / 采集方式

```bash
cd CATANet
# (a) 冒烟测试：验证 EMA 分支建图/前向/EMA更新/接口（几秒）
python scripts/smoke_test_ema_router.py
# (b) 生成多 seed 配置
python options/train/gen_seed_variants.py
# (c) 训练（按优先级分批；每条命令内部会遍历 SEEDS）
RUN_SET=A3 bash options/train/run_ablfs.sh   # 优先：C4 方差子主张必须多 seed
RUN_SET=C1 bash options/train/run_ablfs.sh   # 只会训 c1_emacenter（c1_dpr 复用 full，可手动跳过）
RUN_SET=A2 bash options/train/run_ablfs.sh
RUN_SET=A1 bash options/train/run_ablfs.sh
# (d) 每个变体训完：测 5 基准并把路由诊断 tee 到日志，再解析成 CSV
python basicsr/test.py -opt options/test/test_CATANet_x4.yml 2>&1 | tee results/<tag>_metrics.log
```

- **PSNR/SSIM** 从测试日志读（Set5、Urban100 两列即可支撑消融；C1 建议顺带测全 5 基准）。
- **路由诊断**（entropy\_norm / usage\_active / router\_scale / xscore\_mean）在验证/测试时按
  block 打印，解析为每 block 一行（参照现有 `paper/data/ablation_perblock_urban100_80k.csv`）。

\caption{Dynamic Prototype Routing (DPR). \textbf{(1)} Tokens generate dynamic
prototypes $P^{\mathrm{c}}$ from the current input by soft assignment
(Eqs.~\eqref{eq:assign}--\eqref{eq:proto_content}, C1); \textbf{(2)} a learnable
query bank refines them through a gate $\gamma$ into the confirmed prototypes $P$
(Eq.~\eqref{eq:proto_refine}, C2); \textbf{(3)} tokens are matched back with a
learnable temperature $\tau$, yielding scores $S$, confidence $x^{\mathrm{s}}$ and
labels $b$ (Eqs.~\eqref{eq:scores}--\eqref{eq:belong}, C3/C4); \textbf{(4)} a
confidence-aware key orders tokens (Eq.~\eqref{eq:sortkey}, C3); \textbf{(5)} IASA
aggregates the reordered tokens with a confidence-modulated global gate $\beta$ and
a soft prototype fallback $\alpha$ (Eqs.~\eqref{eq:iasa_gate}--\eqref{eq:soft_fallback},
C3); and \textbf{(6)} a usage-entropy regularizer balances prototype usage
(Eq.~\eqref{eq:balance}, C4). Solid arrows denote tensor flow, dashed arrows denote
gating/regularization. The yellow tags mark the ablation switches A1/A2/A3
(Tables~\ref{tab:abl_a1}--\ref{tab:abl_a3}); each switch defaults to the
full model and is exactly equivalent to its disabled form.}

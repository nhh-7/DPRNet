\caption{Overall architecture of DPRNet. A $3{\times}3$ convolution extracts shallow
features $F_0$ ($C{=}40$); a stack of $L{=}8$ blocks, each coupling a Token
Aggregation Block (TAB) with local self-attention (LRSA) and a fusion convolution
under a residual connection (Eq.~\eqref{eq:assign} context, Eqs.~(1)--(3)),
produces $F_L$; a global residual, a pixel-shuffle upsampler and a bilinear bypass
reconstruct $I_{SR}$. The contribution is confined to the DPR module inside each
TAB (highlighted), whose data flow $X\to\mathrm{LN}\to\mathrm{DPR}\to\mathrm{IASA}
\to\mathrm{Conv}_{1\times1}\to\mathrm{ConvFFN}$ keeps the TAB interface
$\mathbb{R}^{C\times H\times W}\!\to\!\mathbb{R}^{C\times H\times W}$ unchanged, so
the rest of the CATANet backbone is a drop-in host; DPR is detailed in
Fig.~\ref{fig:dpr}.}
